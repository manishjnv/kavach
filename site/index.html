How it works

Kavach is a small shield that sits in front of any guardrail. It never answers a prompt. It only rewrites it.

1

A prompt arrives in Hinglish

Hindi words in Latin script with loose spelling. A guardrail trained mostly on English reads it poorly.

2

The shield rewrites it in English

One instruction to a small model: rewrite this in plain English, keep the meaning, do not answer it.

3

The guardrail scores both

The higher score wins. If the shield cannot rewrite the text, the prompt is blocked. It fails closed.
