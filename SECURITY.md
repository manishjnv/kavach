# Security policy

## Report a problem

If you find a security problem, don't open a public issue.

1. Open the **Security** tab of the repository.
2. Select **Report a vulnerability**.
3. Describe the problem and the steps to see it.

You get an answer in seven days.

## What to report

- A key or a token in the repository.
- Harmful prompt text in a public file.
- A way to make the shield API answer a prompt and not only rewrite it.
- A way to use the shield API without the 300-character limit.

## What isn't a security problem

- A prompt that the guardrail doesn't flag. This is a benchmark result. Open a normal issue.
